Track A – Exploratory Data Analysis (EDA)¶

Project: Medication Safety Assistant (RAG with grounded citations) Goal of this notebook: understand the data before building the system, find data-quality problems, and decide how to design search (chunking) and evaluation.

Data File What it is
Drug list data/drugs.csv 63 medicines, one row each: chosen FDA label, sections present, links
Label text data/label_sections.csv Official FDA label text (openFDA), one row per label section — the RAG library
Practice patients test_set/patients.csv Synthetic patients (no real data), split into dev and test
Correct answers test_set/expected_flags.csv Warnings the system should raise, each tied to a label sentence

How to run: from the project folder, pip install pandas matplotlib jupyter, then open this notebook and Run All. Section 8 summarises the findings.

CHUNK, OVERLAP = 250, 50
def n_chunks(words):
    return 1 if words <= CHUNK else 1 + -(-(words - CHUNK) // (CHUNK - OVERLAP))
sections["est_chunks"] = sections.n_words.map(n_chunks)

per_drug = sections.groupby("drug").n_words.sum().sort_values()

5b. Are interacting drugs named directly, or only by drug class?¶

Labels often say "strong CYP3A4 inhibitors" or "NSAIDs" instead of naming each drug. A simple name search will miss those. Here we count, for each drug, how many of the other 62 drugs are named in its Drug Interactions or Contraindications sections, and how many class-level phrases appear.

In [10]:
SYN = {"sulfamethoxazole and trimethoprim": r"sulfamethoxazole|trimethoprim|cotrimoxazole|co-trimoxazole",
       "potassium chloride": r"potassium chloride|potassium supplement",
       "isosorbide mononitrate": r"isosorbide"}
pattern = {d: re.compile(r"\b(" + SYN.get(d, re.escape(d)) + r")\b", re.I) for d in drugs.drug}
CLASSES = {"CYP3A4/CYP3A": r"CYP3A4?", "P-gp": r"P-gp|P-glycoprotein", "CYP2C9/2C19/2D6": r"CYP2C9|CYP2C19|CYP2D6",
           "NSAIDs": r"NSAID|non-?steroidal", "anticoagulants/antiplatelets": r"anticoagulant|antiplatelet",
           "QT-prolonging drugs": r"QT", "potassium-raising drugs": r"potassium"}

ix_text = sections[sections.field.isin(["drug_interactions", "contraindications"])].groupby("drug").text.apply(" ".join)
named = pd.DataFrame(0, index=drugs.drug, columns=drugs.drug)
for a, text in ix_text.items():
    for b in drugs.drug:
        if a != b and pattern[b].search(text):
            named.loc[a, b] = 1
class_hits = pd.DataFrame({c: ix_text.str.contains(p, case=False, regex=True) for c, p in CLASSES.items()})

pairs_named = ((named + named.T) > 0).values.sum() // 2

Findings¶

  1. Coverage is complete. All 63 drugs have a label and a standard RxNorm ID. 62 are prescription labels; aspirin only has an over-the-counter label. 60 of 63 labels were updated in 2025–2026.
  2. EDA caught a data error. The hydrochlorothiazide label is really an olmesartan + hydrochlorothiazide combination (its name uses a hyphen, which the download script missed). The script is fixed; re-download and this check (Section 2) should show 0.
  3. Key sections exist for 62 of 63 drugs. Aspirin (OTC "Drug Facts") has no Contraindications or Drug Interactions section. Aspirin interactions must come from the other drug's label (e.g. warfarin's label names aspirin).
  4. Two label formats. 42 labels use the new format (Warnings and Precautions), 20 the old one (Warnings + Precautions). Search must treat these sections as the same thing.
  5. Text length is very uneven. Sections range from 7 to 4,493 words; 57% are longer than 250 words. In total about 446,000 words (~580,000 tokens): far too much to give the AI at once, so we must search and send only the relevant pieces. Cutting into 250-word chunks with 50-word overlap gives about 2,500 chunks.
  6. Kidney information is scattered. 97% of drugs mention kidney function somewhere, but only 54% in the Dosage section. Dose checks must also search Use in Specific Populations, Geriatric Use and Precautions.
  7. Labels often name drug classes, not drugs. 37% of labels use CYP3A phrases, 40% mention NSAIDs, 27% P-gp. For 5 of 24 expected interaction flags (21%), the partner drug is not named in the cited section (e.g. simvastatin's contraindication says "strong CYP3A4 inhibitors", not "clarithromycin"). A keyword-only system will miss these, so we need drug-class mapping (RxClass) and meaning-based search.
  8. Pregnancy warnings are concentrated. Only a few drugs carry a pregnancy contraindication or boxed warning (ACE inhibitors, ARBs, warfarin). Pregnancy cases test whether the system avoids false alarms for other drugs.
  9. The test set is balanced but small. 44 patients (22 dev / 22 test, every category in both), 10 safe patients (23%), 37 expected flags. Gaps: only 1 moderate flag, 20 of 63 drugs not used in any patient, and most patients take only 1–3 medicines (real patients often take 5–10).
  10. Data quality is otherwise clean. No duplicates, no empty sections, every section has an RxCUI and a DailyMed link, no leftover HTML, and 172 sections correctly keep clinical symbols like "<30 mL/min".
